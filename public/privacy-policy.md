# Privacy Policy for Narahan Discord Bot

Last updated: October 1, 2026

1. Overview
Narahan ("the Bot") is committed to protecting user privacy. This Privacy Policy outlines our practices regarding data collection, usage, and retention.

2. Data Collection & Usage
The Bot only collects non-personal structural data strictly required to maintain bot functionality, system settings, and user features:
- **System & Server Configurations:** Server IDs, Channel IDs, and Role IDs are stored solely to preserve server preferences, system setups, and administrative configurations.
- **User & Entertainment Data:** User IDs are stored to maintain user progress, economy data, and interaction stats within entertainment commands.
- **Message Content:** Message contents processed via Message Content Intent are analyzed transiently in real-time solely to execute commands and are immediately discarded.

3. Information We DO NOT Collect
The Bot **does not** read, record, or permanently store personal chat history, private messages, voice activity, or real-world identification details.

4. Third-Party Data Sharing
We do not sell, share, trade, or transfer any collected data to third parties.

5. Data Retention & Deletion
Stored configuration and progress data are retained as long as necessary to provide bot features. Server owners or users may request full deletion of their stored data at any time by contacting the developer.

6. Contact
If you have any questions or data deletion requests regarding this Privacy Policy, please contact the bot developer via Discord or open an issue on this repository.
